# Developer Onboarding Guide

This document explains how to set up and deploy the CDK + Cognito + Lambda project for new developers.

## Prerequisites

Before starting, ensure you have the following installed:

- **AWS CLI** – [Install Guide](https://docs.aws.amazon.com/cli/latest/userguide/cli-chap-install.html)
- **Node.js v18+ and npm**
- **AWS CDK v2**
  ```bash
  npm install -g aws-cdk
  ```
- **Git**

## Configure AWS Credentials

Each developer should use their own sandbox AWS account.

Run the following command to configure AWS credentials for your personal profile:

```bash
aws configure --profile <your-profile-name>
```

**Example:**

```bash
aws configure --profile jerick
```

**Provide:**
- AWS Access Key ID
- AWS Secret Access Key
- Default region (e.g., ap-southeast-2)
- Output format (default: json)

**Confirm your credentials work:**

```bash
aws sts get-caller-identity --profile <your-profile-name>
```

## Clone the Repository

```bash
git clone git@github.com:your-org/your-cdk-repo.git
cd your-cdk-repo
```

## Create Your Branch

Each developer should work on a dedicated branch:

```bash
git checkout -b dev/<your-name>
```

**Example:**

```bash
git checkout -b dev/jerick
```

## Install Dependencies

From inside the CDK folder:

```bash
cd cdk
npm ci
```

## Configure Your Environment

Create a `.env` file inside the cdk directory.

```bash
AWS_ACCOUNT_ID=<your-aws-account-id>
AWS_REGION=ap-southeast-2
DEV_NAME=<your-name>
```

**Example:**

```bash
AWS_ACCOUNT_ID=123456789012
AWS_REGION=ap-southeast-2
DEV_NAME=jerick
```

## Bootstrap Your AWS Environment

This sets up resources that CDK needs to deploy (only required once per AWS account and region).

```bash
cdk bootstrap --profile <your-profile-name>
```

**Example:**

```bash
cdk bootstrap --profile jerick
```

> **Note:** You do not need to include the `aws://<account>/<region>` format when using profiles.

## Run Tests Locally

To verify that all unit tests pass before deployment:

```bash
npm test
```

## Synthesize the Stack (Optional)

To preview the CloudFormation template generated by CDK:

```bash
cdk synth --profile <your-profile-name>
```

## Deploy Your Stack

Deploy your stack to your AWS sandbox environment:

```bash
cdk deploy --profile <your-profile-name>
```

**Example:**

```bash
cdk deploy --profile jerick
```

After deployment, CDK will display important outputs such as:
- API Gateway endpoint URL
- Cognito User Pool ID
- Cognito Client ID

These values are needed for frontend or Postman testing.

## Test the API

Use Postman or curl to test the deployed API.

### Signup Example

```bash
curl -X POST https://<api-endpoint>/users/signup \
-H "Content-Type: application/json" \
-d '{"email":"test@example.com","password":"Pass1234"}'
```

### Signin Example

```bash
curl -X POST https://<api-endpoint>/users/signin \
-H "Content-Type: application/json" \
-d '{"email":"test@example.com","password":"Pass1234"}'
```

### Protected Route Example

```bash
curl -X GET https://<api-endpoint>/users/profile \
-H "Authorization: Bearer <AccessToken>"
```

## Workflow for Pull Requests

Push your branch:

```bash
git push origin dev/<your-name>
```

Open a Pull Request to the main branch.

GitHub Actions will automatically:
- Install dependencies
- Run unit tests
- (On merge) deploy to shared staging environment

## Updating Resources

If you change Lambda code or CDK configurations, redeploy:

```bash
cdk deploy --profile <your-profile-name>
```

## Cleaning Up Resources

To remove all deployed resources from your AWS sandbox:

```bash
cdk destroy --profile <your-profile-name>
```

Confirm with `y` when prompted.

## Common Issues

### Issue: AccessDeniedException
- **Cause:** AWS credentials missing or expired
- **Fix:** Re-run `aws configure --profile <name>`

### Issue: Bootstrap stack not found
- **Cause:** CDK bootstrap not run
- **Fix:** Run `cdk bootstrap --profile <name>`

### Issue: npm ERR!
- **Cause:** Old node_modules
- **Fix:** Delete and re-run `npm ci`
